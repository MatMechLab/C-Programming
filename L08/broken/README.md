# L08 错误对照

这些文件故意保留错误，不是正确参考实现。

- [swap_loses_value.c](swap_loses_value.c)：逻辑错误，行为有定义。第二条赋值读取的是第一条赋值后的值，所以 `52 47`最后变成`47 47`，旧值52丢失。可以运行，并用临时变量修复。
- [cross_row.c](cross_row.c)：第二个下标越过当前行。每行只有3项，列下标只能为0、1、2；`table[0][3]`不能作为`table[1][0]`的替代写法。此例行为未定义，只分析和检查编译诊断，不运行，也不给它指定一个“正确输出”。

编译器可能没有诊断出某处越界；没有警告不能说明访问合法。
