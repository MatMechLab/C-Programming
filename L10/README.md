# L10 程序与课堂练习

这些程序处理虚构的机器人离线距离记录，单位为毫米（mm），不连接硬件。求和、首次最小位置和阈值计数示例采用最多8项、每项0～3000的课堂约定；这些数值不是某型号传感器的量程，也不是避障安全阈值。

## 阅读顺序

| 文件 | 观察重点 |
|---|---|
| `address_model.c` | 地址值与整数值；读出的副本不会跟随目标变化；指向整数0与NULL的区别 |
| `pointer_parameter.c` | 普通数值副本与地址值副本；通过指针参数修改调用者对象 |
| `swap_readings.c` | 临时整数保留旧值；交换两个对象中的值 |
| `array_interface.c` | 数组形参、有效长度、只读显示与修改首项；容量6但只处理4条 |
| `minmax.c` | 用返回状态与两个输出参数给出最小值、最大值 |
| `practice.c` | 未完成的课堂练习骨架，补两个TODO后再与答案比较 |
| `practice_solution.c` | 求和参考答案；空序列和坏读数的不同处理 |
| `redirect_parameter.c` | 选读：重定向局部指针形参，不会重定向调用者指针 |
| `const_view.c` | 选读：只读访问路径与原对象是否可修改的区别 |
| `closest_index.c` | 选读：同时返回首次最小读数的位置和值 |
| `near_count.c` | 选读：统计不大于给定阈值的记录条数 |

每个正常 `.c` 文件是独立完整程序，单独编译，不要把多个包含 `main` 的源文件一起链接。文件内的 `// [名称]` 和 `// [/名称]` 是代码段标识，不影响C程序行为。

课件对象图中的A、P、S等字母只是地址的示意符号，不是实测地址或C变量名。框内写保存的值，框下写对象自己的地址；框的大小和位置不表示实际字节数或内存布局。实线箭头表示当前指向，带“复制”文字的虚线表示某次值复制。

`address_model.c`先将`*p`读成整数副本`snapshot`，再通过`*p=400`修改原读数；副本仍为420，`p==&reading`仍为1。`zero_ptr`指向有效的整数对象`zero`，因此可读出0；`empty`为NULL，程序只比较它，不解引用。

## 编译与运行

例如，在本目录运行：

```sh
gcc -std=c17 -Wall -Wextra -Wpedantic minmax.c -o minmax
./minmax
```

使用Clang时，将上面的 `gcc` 换成 `clang`。数组与指针练习也可在工具支持时加 `-g -fsanitize=address,undefined`；运行检查只能发现部分问题，仍须满足对象与边界条件。

`outputs/` 保存各程序的实际输出。`practice.txt` 只是尚未完成骨架的输出，不是求和正确答案；完成练习后，应与 `practice_solution.txt` 比较。

## 四种统计接口的约定

本课都用 `1` 表示成功、`0` 表示检测到的失败。这是这些函数的约定，不是所有C库函数都遵循的规则。失败时，输出对象保留调用前的值；这些旧值不能当作本次结果。

| 接口 | 输入范围 | 空序列 | 成功输出 |
|---|---|---|---|
| `minmax(a,n,&low,&high)` | n>0；任意已初始化、可读的int序列 | 失败 | 最小值和最大值 |
| `range_sum(a,n,&sum)` | 0≤n≤8；各项0～3000 | 成功，和为0，可a=NULL | 总和 |
| `closest(a,n,&index,&range)` | 1≤n≤8；各项0～3000 | 失败 | 首次最小项下标及其值 |
| `count_near(a,n,limit,&count)` | 0≤n≤8；各项及limit均为0～3000 | 其他参数有效时成功，计数0，可a=NULL | 满足a[i]≤limit的条数 |

调用者必须真实提供从起点开始的n项存活、已初始化且可读的元素。所有传入指针值必须可合法求值；判空不能检测悬空、虚报长度或任意坏地址。输出参数须指向存活、可写的int对象，不与输入元素重叠；双输出还须指向不同对象。上述函数检查相同输出地址，但不自动检测输出是否落入输入数组。

`minmax`没有0～3000值域限制；它对负数等int序列也适用。`closest`返回的下标表示同一传感器时间记录中的位置，不能解释为障碍物方向。重复最小值用严格 `<` 保留首次；`count_near`使用 `<=` 包含阈值边界。

`set_reading`、`swap_values`、`show`和`reset_first`是突出机制的小函数，直接要求调用者满足源文件注释中的对象与长度条件，并不包含通用错误检测。`swap_values`允许两个指针指向同一对象；统计接口拒绝同址双输出是接口设计，不能概括成C禁止所有同址参数。

## 两个故意错误片段

`broken/const_write.c` 与 `broken/sizeof_parameter.c` 只用于阅读编译诊断，不作为正常程序运行。可以用 `gcc -std=c17 -Wall -Wextra -Wpedantic -Werror -c broken/const_write.c` 查看诊断：前者违反只读访问限制；后者把指针大小误用于数组长度计算。

## 课后综合练习

先使用 `{420,390,450,390}` 和阈值400分别调用三个函数：`minmax`应给390/450，`closest`应给下标1/读数390，`count_near`应给2条。保留原数组和采样顺序，每次先检查返回状态。

再改变为单项、全相等、空序列和范围外读数，解释哪些调用成功、哪些失败，以及失败后为什么不能把旧输出当作新结果。若要把总和与两个极值合并成一个接口，必须重新说明空输入规则：要求同时交付极值时，空序列应失败。
