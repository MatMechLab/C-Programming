## 输入约定与统计规则

本课用整数摄氏温度作为练习数据。`-20～50 ℃`（含两端）是**课堂虚构的有效范围**，不代表某类仪器、环境或真实设备的安全范围。完整汇总读取6个整数，不保存数组；读到一个，处理一个。

每个十进制整数最多四字符（含正负号），各项用空白分隔。`scanf("%4d", &temp_c)` 的结果不为1时，程序打印“输入错误：需要整数温度。”并返回1。固定6项版本在少于6项就遇到输入流结束或转换失败时不打印摘要；多出的第7项及后续内容不读取。键盘只按一次回车通常还会等待输入，与输入流结束不同。

只有处于课堂范围内的整数参与总和、平均值和极值。6项全部转换成功后，`valid_count + invalid_count == 6`；转换失败不算成一条“无效温度”。零个有效项时，总和为0，程序明确说明平均值和极值不计算；不能把极值变量的初始0作为数据结果。第一项有效温度到来时才建立最小值和最大值，再增加有效数。

有效温度总和在 `[-120, 300]` 内，计数在 `[0, 6]` 内，均处于C17最低保证的 `int` 范围内。平均值只在有效数大于0的分支中计算，`(double)sum_c / valid_count` 先转换再除；`%.2f` 控制显示小数位，不改变保存的温度，也不表示增加了测量精度。

`sentinel_sum.c` 与固定6项版本不同：读到 `-999` 立即结束，标记不参与有效数、无效数或总和。没有标记时最多读取6项；还没读满6项且没有标记就遇到输入失败，仍报错退出。标记后的内容不再读取。固定6项版本没有结束标记规则，`-999` 在其中只是一项越界温度。

`do_range.c` 每轮先提示并尝试读取一个整数。转换成功但越界时，打印提示并再来一轮；转换失败则报错退出，不反复处理留在输入流中的错误文本。读到首个有效温度后结束，剩余输入不读取。

`compare_loops.c` 没有键盘输入。初值均为3，`while`首次判断 `3 < 3` 为假，因此不更新；`do…while`先把 `j` 加到4，再判断 `4 < 3` 为假。输出的是实际变量值，分别为3与4。

`for_step_two.c` 的更新是 `i += 2`，进入循环体的编号依次为1、3、5、7；最后更新到9，因 `9 < 8` 为假而停止。它不处理2、4、6，也不会进入 `i == 8` 的一轮。`i` 声明在 `for` 头部，不在循环结束后访问；本例所有中间值都在 `int` 的最低保证范围内。

## `%4d` 的实际限制

字段宽度限制一次转换至多处理四个输入字符；四字符十进制数字的正值至多9999，负值不小于-999，因此本例转换结果可由符合C17最低要求的 `int` 表示。它**不验证完整数字文本、项间空白或整行**，也不是通用输入解析方案。

| 输入片段或完整输入 | 实际行为 |
|---|---|
| `000018 21 50 18 -20` | 六次转换读到 `0、18、21、50、18、-20`；没有读到输入者可能想表达的单个18 |
| `00501 2 3 4 5` | 六次转换读到 `50、1、2、3、4、5`；一个超宽文本被拆成两项 |
| `10000 1 2 3 4` | 六次转换读到 `1000、0、1、2、3、4`；1000被判为越界 |
| `18-25 21 50 18 -20` | 仍可读到六个整数；没有验证第一、二项之间的空白 |
| `18 -25 21 50 18 -20xyz` | 第六次转换成功后直接统计，尾随 `xyz` 未被拒绝 |
| `18x -25 21 50 18 -20` | 第一轮读到18，下一轮在 `x` 处转换失败，报错且不输出摘要 |
| `18 -25 21 50 18 -20 9999` | 只统计前六项，第七项未读取 |

这些用例在验证中标为“输入约定外的局限观察”，不能说成程序成功拒绝了不符合输入约定的整行。本课没有构造或运行可能超出 `int` 可表示范围的无宽度限制转换。

## 构建、运行与核对

```bash
gcc -std=c17 -Wall -Wextra -Wpedantic code/L05/temp_summary.c -o /tmp/l05_summary
/tmp/l05_summary
clang -std=c17 -Wall -Wextra -Wpedantic code/L05/temp_summary.c -o /tmp/l05_summary_clang
python3 -B validation/verify_l05_code.py --clang /path/to/clang
python3 -B validation/verify_l05_revision_code.py
```
